# Информатика для первокурсника

**Тема:** Системы счисления  
**Автор:** Твоё Имя (или ник)  
**Цель:** Краткий справочник по переводу чисел между системами счисления.

## Файлы

- `glossary.md` — основные термины
- `examples.md` — разобранные примеры
- `sources.md` — источники

## Как читать

1. Начни с `glossary.md` — термины.
2. Затем `examples.md` — примеры с решениями.
3. `sources.md` — если нужно углубиться.
