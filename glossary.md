# Глоссарий

**Система счисления** — способ записи чисел с помощью ограниченного набора цифр. Бывает позиционной и непозиционной.

**Основание системы счисления** — количество различных цифр, используемых в позиционной системе счисления.

**Позиционная система счисления** — система, в которой значение цифры зависит от её позиции в записи числа.

**Непозиционная система счисления** — система, в которой значение цифры не зависит от её позиции (например, римские цифры).

**Двоичная система** — позиционная система счисления с основанием 2. Использует только цифры 0 и 1.

**Восьмеричная система** — позиционная система счисления с основанием 8. Использует цифры от 0 до 7.

**Шестнадцатеричная система** — позиционная система счисления с основанием 16. Использует цифры 0–9 и буквы A–F.

**Разряд** — позиция цифры в записи числа, определяющая её вес.

**Перевод чисел** — процесс преобразования числа из одной системы счисления в другую.

**Вес разряда** — степень основания системы счисления, соответствующая данной позиции цифры в числе.
